# Vice Sun '86 (罪恶阳光 '86)

基于 Three.js 构建的 1986 霓虹迈阿密复古开放世界网页动作驾驶游戏（支持桌面端键鼠与移动端横屏触控）。

- 线上地址：[https://sunsin.exolneverland.com](https://sunsin.exolneverland.com)

## 核心玩法

- **开放街区与跨海群岛**：海滨大道、小哈瓦那、市中心双层立体停车楼、西区货运机场、跨海拱桥（Starfish Causeway）与海星灯塔岛，支持实时昼夜与霓虹光影切换。
- **载具与改装车库**：支持街头抢车、漂移氮气加速、自驾军方犀牛坦克主炮轰击、车载探窗射击，以及阳光改装厂喷漆消星、引擎/涡轮/装甲升级与超跑提车。
- **6 槽武器与掩体战术**：拳击、霓虹棒球棍、9mm 手枪、MAC-10 冲锋枪、泵动霰弹枪、RPG-7 火箭筒；支持步行蹲伏与贴墙/贴车掩体减伤，移动端支持自动吸附锁敌。
- **任务、产业与收集**：10 个电话亭任务、4 处自动分红产业、2 处街头狂暴挑战、7 处飞车特技跳台与 10 个隐藏霓虹图腾，全进度通过 `localStorage` 自动存档。

## 目录结构

- `index.html`：游戏入口、HUD 界面与响应式触控布局
- `js/config.js`：全局参数、多语言文案、武器/车辆/产业/收集品配置
- `js/world.js`：城市街区、立体车库、跨海大桥与海星灯塔岛三维场景构建
- `js/player.js`：角色移动、蹲伏掩体、6 槽武器射击与锁敌系统
- `js/vehicles.js`：车辆物理、漂移、车损爆炸与坦克炮塔控制
- `js/police.js`：1 至 5 星通缉热度、警车围堵、特警与武装直升机追击
- `js/living_city.js`：市民 NPC、街头突发事件与动态交通流
- `js/missions.js`：电话亭任务、资产收购分红与街头狂暴挑战
- `js/garage.js`：改装厂 UI、军火补给与本地存档管理
- `js/hud.js`：小地图雷达、状态栏与屏幕提示
- `js/audio.js`：Web Audio 合成引擎声、警笛、爆炸与复古电台音乐
- `js/main.js`：主循环、输入适配、镜头跟随与自动存档调度
